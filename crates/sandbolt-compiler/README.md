# sandbolt-compiler

Lowers validated ECMAScript syntax trees into verified bytecode images, handling scope resolution, closures, modules and jump assembly. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
