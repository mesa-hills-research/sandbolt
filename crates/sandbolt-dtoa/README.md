# sandbolt-dtoa

Parses and formats ECMAScript numbers (`dtoa`, `atod` and integer conversions) in safe Rust, ported from QuickJS-ng v0.17.0. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
