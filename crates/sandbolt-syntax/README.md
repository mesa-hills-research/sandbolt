# sandbolt-syntax

Lexes, parses and validates ECMAScript scripts and modules into an arena-backed syntax tree with strict and Annex B early-error checks. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
