# sandbolt-bytecode

Defines the QuickJS-ng v0.17.0 instruction set, bytecode image format, binary codec, structural verifier and disassembler. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
