# sandbolt-bigint

Implements arbitrary-precision integer arithmetic, bitwise operations and string conversions for ECMAScript `BigInt` values, with allocation accounting and interrupt checks. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
