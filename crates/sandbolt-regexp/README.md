# sandbolt-regexp

Compiles and executes ECMAScript regular expressions using a backtracking bytecode VM modeled on QuickJS-ng's `libregexp`. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
