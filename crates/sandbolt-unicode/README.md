# sandbolt-unicode

Provides Unicode property lookups, case conversion, normalization and identifier tables for ECMAScript, ported from QuickJS-ng v0.17.0. This crate is an internal component of [Sandbolt](https://github.com/mesa-hills-research/sandbolt/blob/main/README.md), a pure-Rust port of QuickJS-ng v0.17.0. Most users should depend on `sandbolt` instead.
